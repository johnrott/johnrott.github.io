FPGA ACCELERATION / VITIS HLS

Binary neural network

An FPGA implementation of MNIST inference using XNOR, popcount, bit packing, and HLS dataflow.

31×batch speedup vs ARM
89.39%MNIST accuracy
48.3kimages / second
Implementation details

64-bit packed activations replace scalar binary operations. Eight input pixels arrive per word; binarization runs on chip. Layer processes overlap through HLS dataflow.

Measured on AUP-ZU3 at a 10 ns clock. Speedup refers to the full 10,000-image batch; accuracy matches the golden implementation.

C/C++ · XNOR/popcount · Bit packing · Dataflow
